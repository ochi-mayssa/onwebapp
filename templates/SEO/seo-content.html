{% trans "Underperforming" %}

{% trans "Pages receiving less traffic than their potential." %}

{% trans "High Priority" %}

{% trans "These pages have keywords ranking on page 2-3 of search results, or content that targets high-volume queries but isn't performing. Small optimizations — better headings, internal links, refreshed content — can push them onto page 1." %}

{% trans "Outdated" %}

{% trans "Content that needs fresh information or updated references." %}

{% trans "Medium Priority" %}

{% trans "Old statistics, broken links, outdated screenshots, and references to deprecated tools reduce trust and rankings. Regular content refreshes signal to search engines that your site is maintained and authoritative." %}

{% trans "Cannibalizing" %}

{% trans "Multiple pages competing for the same search intent." %}

{% trans "High Priority" %}

{% trans "When two or more pages target the same keyword and intent, search engines struggle to decide which to rank. Consolidate, redirect, or differentiate these pages to concentrate authority and improve rankings." %}

{% trans "Thin" %}

{% trans "Pages that don't sufficiently answer the user's query." %}

{% trans "Medium Priority" %}

{% trans "Short, shallow, or incomplete content rarely ranks. Expand thin pages with comprehensive information, examples, visuals, and actionable insights to match what top-ranking competitors provide." %}

{% trans "Disconnected" %}

{% trans "Content with weak internal linking or unclear topical relationships." %}

{% trans "Low Priority" %}

{% trans "Pages that exist in isolation — with no internal links pointing to or from them — are harder for crawlers to find and users to discover. Build internal links to connect related content and distribute authority." %}
