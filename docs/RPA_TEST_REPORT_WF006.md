## 2. Failure Analysis
**Blocking Issue**: The current Stripe Webhook handler (`webhook`) **only** handles `checkout.session.completed` (initial purchase).
*   **Renewals Ignored**: Recurring payments do not extend the subscription.
*   **Failures Ignored**: Failed recurring payments do not trigger alerts or suspension.
*   **Invoices Disconnected**: Project invoices generated by `automated_invoice_generation` are DRAFT but never marked PAID via Stripe because they aren't linked to the checkout session logic yet.
